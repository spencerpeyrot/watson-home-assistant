# Gateway bearer authentication

`service/auth.py` provides fixed-role bearer authentication for the one-owner, one-device V1 setup. The Cube Pi hosts the API and worker. Deployment supplies `CUBE_OWNER_ID`, `CUBE_DEVICE_ID`, `CUBE_OWNER_TOKEN`, and `CUBE_DEVICE_TOKEN` through process environment. `CUBE_OPERATOR_TOKEN` is optional and grants health-route access only. `CUBE_WORKER_TOKEN` is optional and maps to a worker role scoped to the configured owner/device; it can call only the internal local-tool route. Tokens must be distinct, contain at least 32 characters, and contain no whitespace.

`authenticator_from_environment()` reads process variables only. It does not open `.env` or log secret values. `CredentialAuthenticator` stores SHA-256 digests and checks every configured digest with `hmac.compare_digest`. HTTP requests use `authenticate_http`; the device WebSocket uses `authenticate_websocket`. The durable API maps each role to a fixed owner/device identity and never trusts identity fields from request bodies.

The device token can create sessions/jobs and access only its mapped device's sessions, voice/event sockets, and jobs. Owner token can use owner-scoped dashboard/API routes. Optional operator token can read health only. Worker token cannot read jobs or use owner/operator routes; `/internal/v1/local-tools` also checks the configured device, active job, job revision, and all task correlation IDs before delivery. Serve remote HTTP/WebSocket traffic behind TLS; the Pi clients reject cleartext remote URLs.

`OPENAI_API_KEY` remains a separate API secret. The Pi API/worker need it for model requests; the timer client uses the same key for reminder TTS. Muse voice mode also requires `TYPESAFE_API_KEY` for primary Jev decisions; OpenAI Decisions is the fallback. Neither authenticator nor provider factory loads `.env`. API, worker, and timer secrets now live in root-owned mode-0600 Pi service files; initial app migrations are applied. Systemd templates live in [`deploy/`](../deploy/); release switching is handled by [`scripts/release_switch.py`](../scripts/release_switch.py). Credential rotation and private remote dashboard access remain open. Rotate tokens by changing process configuration and coordinating the device-token update; no in-app token issuance or rotation route exists.

`service.server:create_app` composes the environment-backed auth, Live provider, and durable API. It opens/closes the PostgreSQL pool in app lifespan; migrations stay explicit by default. After setting process environment, run `uv run python -m service.migrate`, then `uv run uvicorn --factory service.server:create_app --host 127.0.0.1 --port 8080`. Local development may prefix commands with `uv run --env-file .env`; production should inject secrets through its secret manager or service environment. Set `CUBE_AUTO_MIGRATE=true` only when startup migration is an intentional deployment choice.

Run durable jobs in a separate process with `CUBE_ARTIFACT_DIR` set to a persistent writable path: `uv run python -m service.worker`. Set the same path for the API process; `service.server:create_app` uses it for owner downloads and tombstone cleanup. The worker composes LangChain Luna/Sol clients, OpenAI web search, the bounded Sol agent, LangGraph PostgreSQL checkpointing, owner memory, and artifact storage. It does not apply application migrations. Local development may use `uv run --env-file .env python -m service.worker`. Composition does not contact OpenAI; calls happen only when queued work executes.

To enable Pi-local speaker and power controls, set `CUBE_WORKER_TOKEN` identically in API and worker environments, plus `CUBE_INTERNAL_API_URL` in the worker environment. Use `https://` remotely; `http://` is accepted only on loopback. The worker exposes these tools only on Luna's authenticated simple-task route and records them in the action ledger. For Home Assistant lights, also set the reviewed comma-separated `CUBE_LOCAL_LIGHT_ENTITIES` allowlist. The Pi event client stores each action before execution and reports verified speaker state. Leave the bridge values unset to disable local tools. No host or token is currently configured.
